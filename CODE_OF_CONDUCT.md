# Code de conduite

## En bref

Sois correct. Critique le code, pas les gens.

## Ce qui est attendu

- Accepter qu'on ne soit pas d'accord, et argumenter sur le fond.
- Dire ce qu'on n'a pas vérifié plutôt que de laisser croire qu'on l'a fait.
- Accueillir les questions de débutants comme des questions, pas comme du bruit.

## Ce qui ne l'est pas

Harcèlement, insultes, remarques discriminatoires — sur l'origine, le genre,
l'orientation, le handicap, l'âge, la religion ou quoi que ce soit d'autre —,
publication d'informations privées, et toute forme d'intimidation.

## Portée

Ce code s'applique partout où quelqu'un représente le projet : issues, pull
requests, revues de code, discussions.

## Signaler

Écris au mainteneur via un [avis privé](https://github.com/myqzurdux3/cocorico/security/advisories/new)
ou en message direct. Les signalements sont traités discrètement.

Le mainteneur peut supprimer un commentaire, refuser une contribution ou
bloquer un compte. Le projet est petit : ces décisions se prennent au cas par
cas, sans procédure formelle, et sont expliquées à la personne concernée.
